## 分阶段封板

**M0：规格校准已完成；本地 M1 准备已实施。** 运行系统升级为4.1。本地指标、镜头、叙事、观众端与成片闭环均有实际验证；无云、真实模型或官方数据就绪结论。

**M1a：云通路与提交路径演练。** 用合法测试片/合成输入完成C01–C05的基础部署、一次真实Agent工具调用和最小页面结果，以及C14的仓库/URL保存路径演练；不以未来考试回执、正式数据或完整增强成片为启动条件。账号未到时可并行完成C06–C10的本地Adapter、镜头、证据和渲染开发，CDK本地合成也可先做，但M1a仍待云实测。

**M1b/M2：正式训练素材闭环。** 官方片到达后，结合C06–C10及C04正式内容验收，在两官方训练回合跑完理解、叠加、复核、成片。此时才认证官方训练输入链路；保留错误与人工修订分母。48秒样本不能证明比赛级普遍准确率。

**M3：陌生片演练。** C11至少一次完整120分钟演练，分别记录T+90可评版本和T+120提交检查。尽量用与训练分开的合法镜头验证；反复运行同一训练片不称为泛化。若不能在90分钟内达到目标，先修瓶颈/减少图层和叙事，再做针对性复测，不把慢的演练写成通过。

**M4：考试发布。** 18:00后处理抽签片，完成逐句/逐镜头复核与CloudFront发布，才更新正式可提交状态。

## 云端工程接口（仍为拟新增，不是现有云 API 承诺）

`POST /jobs`接收受控素材对象、数据版本与处理配置，返回jobId；`GET /jobs/{id}`返回明确的阶段/错误；`GET /releases/{id}`返回不可变发布清单。上传授权、创建任务、编辑和发布均需要制作端身份。Agent采用内部Evidence工具接口，不能直接写发布对象。

StoryPlan至少保留：素材哈希、队伍/回合/镜头ID、原字段语义、事件/可用时间、证据引用、图层来源及区间、原片到输出时间映射、模型和提示版本、人工修订、review状态。

指标层与旧演练数据并行版本化迁移，不全局替换名为leverage的字段。先在Adapter将官方语义写明，再由显示和比较层决定可用操作；无定义不参与跨球员或跨回合的定量比较。

## 本轮没有实施的外部动作

未创建/变更GitHub远端仓库，未改原仓库可见性，未授予赛事App权限，未部署收费AWS资源，未绑定Portal或提交URL。正式部署与绑定要依据真实账号和准确服务信息执行；本轮完成策略、规格及可独立推进的本地4.1开发、测试和交付。
