# CourtLens 本机产品验收报告

验收日期：2026-09-22。对象：本次交付的 CourtLens v2 本机单用户工作台。结论：已完成本机产品闭环与下列实测，可用于自有合法视频的人工辅助复盘；不是 NBA 专有模型复现、生产级公网服务认证或正式参赛验收。配套原始日志、截图与独立审查放在交付包的“验收证据”目录。

## 真实发现与修复

早期原型的独立审查发现视频换源后错误绑定、陈旧轨迹保留、导出未核对指纹、空轨迹注释、云规划器同一轮读取与发布等问题。失败快照被拒绝，未改写为通过。产品阶段进一步修复：

1. 人工画线曾可能间接放开未校准自动追踪；现分离 `origin=manual`、`frame_reviewed`、来源说明，并保留原镜头校准状态。
2. 取消/失败终态早于目录清理；现清理与状态写入按确定顺序完成，回归用事件屏障复现而非加等待掩盖。
3. 超大CSV字段和极大整数时长导致HTTP断开；现返回明确400及字段位置/大小提示。
4. 视频轨短于音轨导致读取不存在的帧；第一次仅看0.1秒容差仍不足。第二次改为按真实画面覆盖核对导出帧数；WebM缺少时长字段时读取画面包时间戳。2.08秒音频/2秒画面和WebM反例均已独立复验通过。

版本迭代沿用同一赛题账本，保留三个早期失败快照，再冻结修复后的产品候选。独立评审上下文与作者分开，但使用同类模型，不能称为模型独立的专家认证。当前收益由可复现反例、修复和复跑证明；没有把失败稿到首个可用稿冒称“双盲胜出”。
