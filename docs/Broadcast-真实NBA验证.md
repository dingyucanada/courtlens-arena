# 真实 NBA 视频验证

更新：2026-09-30。此记录区分软件功能、模型输出与逐帧核查，不用流程测试数量替代识别准确率。

## 素材与范围

实际使用 NBA 官方频道的 [独行侠对火箭集锦，2025-01-01](https://www.youtube.com/watch?v=HjzSVTdTM8M) 前 48 秒，本地转为 1280×720、25fps 的无声 MP4。输入 SHA-256：`10dc5a80343dc97890fc89111fb40997565be2fe48732f815cb4af6902f7f24d`。去掉原声是为了独立检查视觉理解，不能把原解说转写当作视觉结果。

这段集锦包含剪辑和重复画面，不能当作连续 48 秒进攻。赛方两段训练回合**合计约 48 秒**，尚未下发。测试用 NBA 原片、模型权重、检测预览和 API 原始响应均在被忽略的本地 workspace，仓库不打包这些比赛视频。

同场背景使用 NBA 比赛 ID `0022400460`，ESPN 事件 ID `401705026`。背景导入工具保留 ESPN 来源、比赛日期、主客队映射、22 名有出场记录的球员和选定的 25 条第一节逐回合记录。该记录的比赛时钟不是视频时间，不能直接拿来画图或定解说入点。没有官方 xFG、GRAV 或 LVG 数据，因此测试片不显示这三项数值。

## 已完成的实际运行

- 篮球专项 RF-DETR + ByteTrack 在完整 48 秒上分析 240 个真实取样帧，推理用时 34.9 秒，生成 H.264 候选框预览。框数量是检测输出数量，不是准确率或人数。模型、权重许可及限制见 [CV 实测记录](Broadcast-CV-实测.md)。
- 该模型已通过真实 `BroadcastService` 上传与 `cv` 任务路径运行，产生待审轨迹及私有逐帧证据。浏览器连接的本地服务也已配置该执行器。
- StepFun 接受并处理了实际视频及源帧。最小单帧读数测试正确输出 DAL/HOU、白/红球衣、0–0、第一节 11:42，耗时 2.83 秒。这是一帧的实测，不能外推整片准确率。
- 同场背景导入、刷新恢复、跨项目任务隔离、发布来源记录和 AI/人工复核身份区分已实现。发布包保留实际引用的背景记录，AI 复核不会标记为人类已确认。

## 导致路线调整的反例

直接要求模型看完整视频并输出人物、动作、坐标与战术，得到过错误球员、错误得分和错误时间窗。短片复核也出现过把补篮动作误判为抢断的结果。给模型完整 PBP 后，还出现把画面外的比赛事件硬塞进当前视频的问题。部分请求耗尽输出预算，没有可用答案。

因此整段理解只负责候选，不能直接发布。专项检测提供几何候选，比分牌单独读数，同场逐回合记录只在球队、节次、比赛时钟与比分变化一致时参与交叉核对。重复镜头和跨剪辑时钟跳变必须拒绝直接映射。不能把球衣颜色组直接改成球队，更不能把轨迹 ID 改成球员姓名。

## 实际解说成片

真实项目 `6c3687c163214e9899dba0687a0bea9a` 的修订11已输出48秒H.264/AAC成片，发布ID `9752829423b04928aaf8c4da0e55b24f`。三句普通话语音由真实StepFun TTS生成，起点20.8、24.8、42.4秒，实测长度3.2075、3.6890、3.1590秒。均无需变速、未截尾。独立AI检查发布文件hash、视频/音轨PTS和证据时间关系，未将此标成人类审核。

内容为华盛顿底线出手、莱夫利跟进与补篮结果、申京掩护和格林切入。StepFun两份初稿因节点数/结构等问题被拒绝，根代理对真实首稿做了明确AI编辑：压成三句、缩短文字、校正发布时刻，并增加经源帧核对的42.40–42.72秒路线示意。不能称为完全自动视频解说，也不能称为自动球场标定轨迹。正式结果句24.8秒晚于24.0秒比分牌与同场PBP佐证。

## 当前验收边界

已有实际可播放成片，但语义理解仍需逐条复核。AWS 账户未下发，CloudFront/CDK/Agent 服务的云端端到端运行尚未验收。开源模型在本机成功运行，不等于已部署到 SageMaker 或已达到 NBA 生产环境准确率。

## 新增能力的独立复核

同步观赛在开头、节点边界、空档、短时箭头结束、片尾及倒拖逐点验证：无当前节点时清空解说和依据，不保留上一句，不提前展示结果。战术库有10条一手来源概念与按日期过滤的球队背景，只供制作检索；曾发现全片候选可诱导提前解说，已撤下故事模型中的自动候选注入。当前没有逐节点战术语义自动验真能力。

同一真实项目的三种StepFun文本提议实测：普通话1次得到3节点并通过服务端校验，仍需事实复核；英文2次因标题字段/节点数错误被拒；粤语2次因旧号码格式守卫/多余字段被拒。繁体号码已修复但未重跑该模型案例。不能把此结果称为三语生成已全部验收，更不能推断三语配音可用。
