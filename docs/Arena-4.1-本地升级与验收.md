# CourtLens Arena 4.1 · 本地升级与验收

2026-09-28。本版回应培训后的比赛要求，先完成不依赖 AWS 的产品闭环。所有随包比赛数据、视频和动态镜头 fixture 都是合成演练；没有将本地证据编排称为真实视频模型理解。新版使用 NBA 蓝、红和海军蓝，保留四个真实工作区及浏览器项目、修订、备份和本机成片库。

## 实际新增能力

| 场景 | 本版可完成的操作 | 边界 |
|---|---|---|
| 观众看懂一次选择 | 以一个核心问题展开视频，最多三个有依据的讲解点；同一时刻切换原片/增强；查这一刻的证据 | 指标和解说依据实际画面时间，未来结果不会提前展示 |
| 制作员接入指标 | 导入 `courtlens-metrics/2`；同时保留 shot/event/possession/player/season、持/无球、原单位、来源和字典版本 | 赛季6.2不是回合概率；百分数62不会乘成6200%；正式字典需另接 |
| 分析员校准移动镜头 | 分镜头点击地面锚点，补时间关键帧、独立检查点、误差阈值和遮挡区间 | 人工关键帧插值，没有自动光流、身份识别或空中球3D；缺检查或超阈值自动隐藏 |
| 导演编辑与复核 | 编排片单、修改逐句文字/箭头；下载已审 StoryPlan；原提议、原文及父版本保留 | 改动撤销复核，旧成片明确标为历史；校验器不认证所有自然语言或篮球因果 |
| 独立交付 | 同一已审 StoryPlan 可送进无浏览器的 Node Canvas/FFmpeg 渲染器，输出真实 MP4、VTT 和不可变清单 | 静音；macOS中文配音是另一条可选链路，未冒称Polly已接入 |
| 模型接入准备 | 真实解码关键帧证据包、提议JSON合同、提供者/模型/提示词/请求参数、独立推理与渲染缓存身份 | 默认 `deterministic-local`；导入提议是 `imported-proposal`，真实模型调用仍待验 |
| 现场收敛 | 本地验收清单和T+50/70/90/120演练时钟；渲染里程碑需要真实输出指纹 | 短流程已实测，完整陌生片120分钟演练尚未执行 |

指标按声明语义操作；几何距离不代替 Gravity，未知尺度 Leverage 不被便利地归一化。Adapter v2 已明确视频绝对秒，界面拒绝再次整体偏移。动态校准与网页、独立渲染共享 `playAt/storyFrameAt`，保持导入镜头编号和原始轨迹不变。人工箭头以最终已审计划为准，编辑或删除不会在原片旧标注里复活。

## 运行

项目根目录运行：

```sh
python3 tools/launch.py --port 8765
```

进入 `http://127.0.0.1:8765/arena/`。服务仅绑定本机，视频与数据分别保存在浏览器、本机工作区；它不是多人账号或云同步系统。运行日常网页不需要 Node。启动器优先加载本版10页PPT，历史18页PPT另外保留。

独立 MP4 渲染需要 Node 20+、FFmpeg/FFprobe 和明确提供的中文字体；安装锁定依赖后：

```sh
npm ci
node tools/export_arena.mjs --story-plan reviewed.json --video source.mp4 --font /absolute/path/to/chinese-font.ttf --release-dir workspace/releases
```

字体不能由系统默认值偷偷替换。清单绑定实际字体、渲染代码、Node/native canvas/FFmpeg 资产及源片指纹；生成缓存与最终内容渲染缓存分开，缓存命中前核对实际文件。渲染身份相同仍按具体 planHash 区分发布，以保留模型与人审来源。CLI需要恒定fps输出网格；VFR或官方片逐帧对齐需另外复核。本次在 macOS 实机运行，尚未做 Linux/Fargate 容器实测。

准备实际解码证据帧：

```sh
python3 tools/prepare_video_evidence.py --video source.mp4 --output workspace/frames-new --times 8,9,10.5 --source-label '合法素材来源说明'
```

输出每帧的请求时间、实际PTS、帧序号、PNG指纹和源片指纹。它不认证球员、事件、来源许可或模型推理。只向随后工具提供经选择的真实帧；不把任意文字答案包装成视觉观测。详见 [StoryPlan](Arena-story-plan.md)、[动态镜头](Arena-dynamic-camera.md)、[指标合同](Arena-metrics-v2.md)。

## AWS到达后的退出条件

本版没有改旧公开站点或向其上传新素材。云通路仍须在赛方真实账号/区域/允许服务中完成CDK部署、Agent工具实际调用、CloudFront访问、制作权限拒绝、私有仓库读取及Portal保存路径验证。官方训练片需独立运行两回合并逐句逐镜头复核；随后做陌生片完整120分钟演练并证明T+90已有可评版本，考试片发布后才认证正式可提交。部署文件合成或本地模板不能代替这些云实测。
