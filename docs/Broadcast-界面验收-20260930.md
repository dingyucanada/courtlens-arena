# Broadcast 界面改版验收

本次仅调整 Broadcast 制作应用与公开展示页的视觉和操作呈现。主界面采用浅灰背景、白色面板、系统字体及蓝色操作按钮；导航更新为「素材、分析、解说、导出」。公开预览中的工程说明和历史入口收进演示说明，素材页的更换视频默认折叠。已烧录字幕的成片不再默认叠加第二套浏览器字幕，VTT 轨道仍可选择。

## 实测

- 1440×900 与 390×844：真实 48 秒视频在四个操作面板间切换时保留同一视频元素、暂停状态与 22 秒位置；没有横向页面溢出或 JavaScript 页面错误。
- 成片页：真实视频可解码、片段解说随时钟变化、详情抽屉可用；字幕不重复显示。
- 现有完整浏览器流程通过 22 项检查，覆盖上传、实际取帧、观察确认、时间绑定箭头、审核、MP4 导出、原片切换、手机布局以及修改撤销审核。
- 公开演示：36 秒合成视频可播放，回合跳转保留暂停状态；手机布局没有横向页面溢出，也没有请求未部署的制作 API。

截图与测试结果保存在本机忽略目录 `workspace/apple-ui-20260930/`。真实 NBA 测试视频未加入公开包。本次未调用外部模型，未改变官方指标口径，也未完成 AWS 比赛账户部署。
