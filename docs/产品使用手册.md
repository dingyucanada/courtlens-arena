# 产品使用手册

本手册对应 CourtLens v2 的本机项目工作区。项目、视频和导出文件保存在运行服务的当前设备，网页不会把素材发往云端。当前没有账号或团队空间，请不要把服务映射到公网。

## 一、启动后先检查什么

运行 `python3 server.py --port 8765`，打开 [项目工作区](http://127.0.0.1:8765/projects.html)。停止服务按 Ctrl+C。右上角“本机功能”显示视频核验与成片导出是否可用：导入持久视频需要 FFprobe；导出还需要 FFmpeg 和 Pillow。可选中文配音另需 macOS 本机 `say`。缺少依赖时先按照 [架构与运维](产品架构与运维.md) 修复，再重启。

默认工作区是应用目录下的 `workspace/`。只要再次使用同一目录，之前成功保存的项目仍可打开。选择其他 `--workspace` 会打开另一套项目，不表示原内容丢失。

## 二、创建自己的项目

点击“新建复盘项目”，有四种入口。

| 入口 | 准备什么 | 创建后得到什么 |
|---|---|---|
| 从视频开始 | 本地视频、球队信息、来源说明。 | 全视频占位回合，指标为空、追踪为空、未校准，等待人工编辑。 |
| 导入回合表 | 同一视频和按模板整理的 CSV。 | 事件、指标和来源行；不会自动生成轨迹或空间坐标。 |
| 高级数据 | 完整 schema 1.0 JSON。 | 保留已有回合、轨迹与标注；仍需完成项目视频绑定和复核。 |
| 用合成演练体验 | 无需自备文件，但本机需能核验演练视频。 | 明确标记为合成的演练项目，默认待复核。 |

“从视频开始”并没有自动识别这段视频里发生了什么。自动占位的球员、出手时刻、分值和来源都需要替换。创建时视频会传给本机服务并持久复制，不只是浏览器临时打开。

单个文件不能超过 512 MiB。优先使用浏览器可播放的 MP4 或 WebM。带旋转元数据的文件需要先转正，再对转正后的文件校准坐标。较大比赛应先剪成片段，并重新计算该片段的视频秒数及绑定指纹。

如果提示“项目资料已经保存，视频尚未保存”，项目仍在列表中；到“媒体与质量”继续导入即可，不必重复创建。

## 三、编辑回合与指标

在“回合编辑”选择当前回合，依次核对起止、出手、结果确认时间、进攻队、球员与投篮分值。所有时间都用**视频播放位置的秒数**，比赛节钟只是说明文字。开始不能晚于出手，结束必须晚于出手；回合不能重叠。

“结果确认时间”可留空。留空时，系统不会在播放中提前播报结果；不能为了填满字段随便输入一个时间。投篮结果不确定就保留“未知”，但投篮球员和零分占位须在复核前处理。

未知 xFG、Gravity、Leverage 留空，系统保存为 `null`。xFG 的 0.62 表示 62%；Gravity 使用来源原单位；Leverage 只接受本项目明确的 0–1 回合胜率机会差。CSV 中只要有 Leverage，就需勾选口径确认；不了解其含义时应先留空。

新增回合前，需要在现有时间轴留下未覆盖区间。修改回合起止会裁掉区间外数据、裁切注释并撤销该回合追踪镜头校准。请重新检查，不要只改开始时间就导出。

## 四、直接在画面上做人工标注

先保存项目，再点击“画面标注”。等视频指纹和尺寸配对成功，选择回合并暂停视频。可用前后 0.1 秒按钮细调位置；这些按钮按时间移动，不是保证逐编码帧精确跳转。

1. 选择箭头、区域或文字工具，填写标签和有效时间区间。
2. 核对这段时间内没有切镜，勾选画面核对声明。
3. 箭头点击起点、终点；区域点击矩形两角；文字点击一个位置。
4. 检查图形是否遮住球或关键动作，必要时移除重画。
5. 点击“保存标注”，返回项目页进行整体复核并保存。

人工图形是限定时间内的静态标记，不会跟随运动球员，也不是算法检测结果。软件记录 `origin=manual`、`frame_reviewed=true` 和来源说明 `author_note`。人工图形可在原追踪镜头未校准时单独显示；这不会把原来的 `camera_segments.calibrated` 改为真。

相机移动时请缩短区间或分成多个标记。人工标注不能跨已声明镜头边界。画面核对只是你的复核声明，并不证明战术因果正确。

标注页可点击“下载标注草稿”，保存当前数据集 JSON，包含已添加到列表但尚未写入项目的标注；尚未完成选点的图形不在其中。遇到冲突先下载，再回到最新版本核对，避免覆盖另一个窗口的修改。这个下载不包含视频、不创建历史版本，也不自动合并。未下载、未保存的页面编辑会在关闭后丢失。

## 五、保存、复核和冲突处理

“保存项目”把当前内容写入本机数据库，并新增历史版本。未保存编辑不是持久项目；看见“保存成功”和新版本号后，再离开页面。新建、CSV、JSON 和演练项目均从待复核状态开始；网页后续编辑会再次标为草稿。

完成回合、来源和指标检查后，勾选“已核对回合时刻与来源”并保存。这个勾选是操作者声明，不是 CourtLens 或第三方认证。草稿不能通过正常产品导出流程。

若出现“这个项目已经有更新版本”，说明当前修改依据的版本过期。按以下顺序处理：

1. 点击“下载我的草稿”，保留当前数据和表单值。
2. 点击“载入最新版本”。页面还会保留刚才的草稿供下载比对。
3. 比较差异，手工将需要的修改应用到新版，再保存。

没有自动合并功能。项目页的冲突草稿备份包含未通过校验的表单值，不是可直接替代标准数据集的文件，也不是完整项目备份；它与标注页下载的数据集 JSON 格式不同。需要保留草稿时请真正下载，仅存在页面中的备份不保证关闭浏览器后还在。

“版本历史”中的“恢复此版本”会生成新的当前版本，保留原历史。它可能同时恢复当时的视频绑定；对应媒体损坏或丢失时系统会拒绝恢复。

## 六、看懂项目质量

“媒体与质量”显示来源、审核状态、视频指纹、三项指标覆盖、结果时间、镜头校准、轨迹以及回合覆盖时间。

- **阻断项**：结构不合法、仍为草稿、占位未完成、缺少视频指纹等，须先处理。
- **警告项**：例如没有 Gravity、缺少轨迹、部分时间未覆盖。系统可以在能力受限的范围内工作，不能据此补造数据。
- **通过项**：仅表示对应检查通过，不等于素材授权、篮球事实或语义已获认证。

“含指纹”只说明数据里有指纹字段，播放和导出还会核对实际文件。时长相同也可能是不同视频；换源之前必须人工核对事件和空间位置，服务器不会自动重新对齐。

## 七、后台导出与下载

在“导出记录”选择球迷或分析师视角；本机支持时，可选择中文配音，再创建任务。默认不配音，Windows 或缺少 macOS `say` 时不可选择此功能。当前未保存修改会先尝试保存。任务绑定创建时的 revision，并冻结数据和视频副本；之后的编辑只影响后续任务。

本机同时执行一个任务，最多另有四个排队。页面显示排队、运行、完成、失败或取消。渲染阶段按工具报告的帧数显示进度；配音阶段显示已合成的字幕条数，不把它说成视频帧进度。比例不代表剩余时间预测，最后还要核验成片，因此不能仅因进度接近完成就取走文件。

完成后提供：

- `replay.mp4`：带叠加与字幕的视频；选择配音且成功后，含本地中文语音，否则为无音轨模式。
- `replay.vtt`：WebVTT 字幕。
- `replay.analysis.json`：解读、证据及绑定信息，不是原始完整数据集。
- `replay.voice.json`：仅成功配音任务提供，记录字幕、时间、证据和合成参数。

配音只朗读当前已编译字幕，不增加新的比赛事实。两种模式都不保留原视频音轨。字幕过密或语音工具失败会使任务失败，不能得到冒充配音结果的无声中间视频；检查提示后可调整输入，或自行选择不配音重新导出。排队或运行中的任务可请求取消；已完成任务不会因取消而回退。失败、取消或未完成时不提供半成品下载。

刷新或关闭浏览器不会停止仍运行的本机服务任务；关闭服务会中断导出。重启后，中断的排队/运行任务会标为失败，不自动续跑。重新核对当前版本后创建新任务即可。

## 八、常见问题

| 提示或现象 | 处理 |
|---|---|
| FFprobe 不可用 | 安装或把工具放入启动环境可见路径，重启服务；尚不能核验并导入视频。 |
| 导出依赖不可用 | 检查 FFmpeg、FFprobe 和指定渲染 Python 的 Pillow；服务 Python 与渲染 Python 可不同。 |
| 本地配音不可用或失败 | 当前仅支持 macOS `say`；检查本机中文语音是否可用，或按提示处理过密字幕。未修复前可主动改选无配音模式，系统不暗中降级。 |
| CSV 提示第 N 行 | N 是该条 CSV 记录结束的物理行，含换行的引号字段会跨多行；按报错字段检查，不直接拿 N 当第 N 个回合。 |
| Leverage 口径未确认 | 核实来源后显式确认；未知口径留空，不能归一化后硬填。 |
| 视频尺寸或时长不匹配 | 使用真正对应的视频或先在外部重新适配数据；修改指纹不能解决错位。若提示画面轨短于容器时间轴，请先裁齐音视频尾部再导入。 |
| 看不到跟踪图层 | 检查绑定、镜头校准、采样支持区间和轨迹是否存在；人工标注独立核对。 |
| 草稿不能导出 | 完成占位内容、核查来源与时间，勾选复核并保存；不要为解锁导出虚填数值。 |
| 工作区已有服务 | 关闭原服务，或用另一个工作目录；不要删除正在使用的锁文件来抢占。 |
| 重启后没有项目 | 确认使用的工作区路径是否与上次一致；恢复完整备份，不要移动单个数据库文件。 |

最终环境、实测结果和已知限制见 [最终验收报告](最终验收报告.md)。真实 NBA 输入、真实云调用及 Windows 实机兼容仍不能由合成演练或模拟协议测试代替。
