# CourtLens Studio v3 使用手册

Studio 面向需要逐回合复盘的教练、分析人员和制作短片的赛事编辑。它是单用户浏览器应用，项目和视频保存在当前浏览器的 IndexedDB。无需注册；不会把素材上传到 GitHub 或云模型。

## 第一次使用

打开 https://dingyucanada.github.io/courtlens/ 。新建自己的项目，或点击「载入合成演练」体验全流程。演练的球队标记、视频与数据均为合成，不能用于真实比赛结论。

### 场景一：教练赛后复盘

1. 新建比赛项目，填写比赛日期、对手和素材来源，选择「教练赛后复盘」。
2. 进入「回合复核」绑定自己的视频。浏览器读取时长、尺寸和 SHA-256 后将视频保存在本机。文件上限 512 MB；实际可用容量以浏览器配额为准。
3. 导入 CSV / JSON 回合表，或在视频相应时刻点击「添加」。CSV 可从设置或导入窗口下载模板，最多 2,000 条记录。导入前会显示条数和检查提示；追加遇到重复 ID 会拒绝，替换会保留旧修订历史。
4. 逐条核对开始、结束、出手和结果时刻，填写球员、结果、标签与笔记。所有时间都是原视频秒数。确认内容后点击「确认本条已复核」。
5. 到「数据分析」按球队与球员姓名组合、标签或结果筛选。相同球队内的球员名必须能唯一识别人；同队同名请在输入名称中附加号码或稳定 ID。未知结果不计入命中率分母；没有 xFG 的回合不补零；没有坐标就不画虚构投篮点。
6. 从「报告与交付」下载 HTML 复盘报告。用浏览器打开后可打印或另存为 PDF；报告包含当前保存版本、统计口径、来源和复核状态。

### 场景二：赛事编辑制作短片

1. 建立「赛事内容制作」项目，并完成视频和回合导入。
2. 在分析页筛选需要的回合，点击「将筛选结果加入片单」，或逐条添加。
3. 在「片单制作」调整顺序、标题和入出点。片段范围必须在原回合内。允许重复选取同一回合，统计不会重复计数。
4. 保存后点击「预览片单」检查顺序。未保存的表单会阻止切换页面或执行会覆盖草稿的操作。
5. 完成所有回合复核，到交付页批准项目。更换视频、编辑数据或修改片单会撤销批准，修改回合还会撤销该回合的复核。
6. 点击「录制并下载」。浏览器会按实际播放时间生成无声 WebM，画面包含片段序号、球员、原视频时间及按时揭示的结果。最长 180 秒；请保持页面可见。原视频声音不进入成片。

WebM 录制需要浏览器支持 Canvas captureStream 和 MediaRecorder。代码检测能力，遇到不支持、后台页面、卡顿或取消会明确停止，不能把失败状态算作导出成功。实时录制可能有帧级误差，容器可能不携带可随机定位的时长索引；需精确剪辑、MP4、原有本机标注或后台处理时，使用随源码提供的 FFmpeg 本机工作台。两种工作区不自动同步。

## 数据格式

CSV 基本列：`id,start,end,shotTime,resultTime,shooter,team,points,made,tag,notes,xfg,x,y,source`。

- `id` 必须唯一；`points` 为本次出手分值 2 或 3，投失也填写分值。
- `made` 接受 made/missed/unknown、true/false/null 或命中/未中/未知。
- 缺少 shotTime/resultTime 时暂用回合结束时刻，并明确提示人工校正；不会声称自动对齐。
- `xfg` 为来源提供的 0–1 命中概率；`x,y` 为半场归一化坐标，必须同时填写或同时留空。
- CSV 支持引号、逗号、换行、BOM；导出的文本做表格公式注入防护。
- JSON 接受 Studio 回合数组或 `{plays: [...]}`，也兼容原 CourtLens `possessions` 数据格式的事件转换。转换会提示能力范围；逐回合原记录（含 Gravity、Leverage、轨迹和标注）及指标语义保存为只读证据，在回合复核页可展开查看，项目 JSON 备份包含它们。修改复盘字段不会改写原始记录。当前统计、CSV、HTML 报告和 WebM 不使用这些高级字段，轨迹坐标也不会冒充半场投篮坐标。完整比赛、球员等顶层上下文需保留原 JSON，使用原证据工作台。
- 回合文件上限 8 MiB；高级语义展开后的导入预算为 16 MiB，超限须拆分文件；项目结构数据上限 32 MiB，备份导入上限 64 MiB，不含视频。项目备份 JSON 是单独格式，请从「导入项目备份」导入。

## 保存、恢复与备份

每次保存形成新修订。版本冲突时拒绝覆盖：先下载自己的草稿，再载入最新版本比对。恢复旧版会产生新修订、保留全部历史，并要求重新复核。归档只是从工作项目列表中移开，不删除素材。

备份下载当前项目的 JSON，不包含视频 Blob。恢复备份会创建一个新项目并取消复核；用户视频需要重新绑定。请同时保留原视频。浏览器保存与导出下载是不同动作：下载文件不会自动改变项目数据。

来源地址、浏览器配置、端口不同，存储就不同。GitHub Pages 与 localhost 不自动互通。清理网站数据、无痕模式结束或卸载浏览器可能删除本机项目；持久存储申请不能替代备份。

## 本机启动

在源码目录运行 `python3 tools/launch.py --port 8765`。

- `http://127.0.0.1:8765/studio/`：与线上一致的浏览器工作室。
- `http://127.0.0.1:8765/projects.html`：SQLite / FFmpeg 高级本机工作区，原流程见产品使用手册。

启动器只选择已有依赖，不会静默安装软件。完整本机视频处理需要 FFprobe / FFmpeg / Pillow；网页版不需要这些组件。

## 范围

当前已经实现导入、编辑、校验、复核、分析、编排、输出和历史恢复。尚未提供云账号、多人权限、跨设备同步、NBA 专有指标模型或任意转播的自动战术识别。用户填写的来源与复核状态不是软件对素材真实性或权限的独立认证。
