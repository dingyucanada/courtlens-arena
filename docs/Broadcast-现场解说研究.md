# 原创现场解说：动作轨与分析轨

2026-10-01。此次核验阅读了公开文字材料，没有播放、试听或测量这些解说员的现场音频。以下是产品写作规则，不是声纹、音色或本人措辞的复刻。

ESPN 的[总决赛解说组采访实录](https://espnpressroom.com/press-release/transcript-espn-nba-finals-broadcast-team-media-conference-call/)讨论了现场解说与分析员互相配合，以及从大量准备资料中选取真正适合播出的内容。这支持把口播与分析信息分轨的设计推断；该文字实录没有给出 Mike Breen 的逐秒解说速度。

央视[《冬奥夺冠时刻 总台这样解说》](https://news.cctv.com/2026/02/23/ARTIlUfCiiColDlkvcaRH1n3260223.shtml)以于嘉为例，介绍将长期准备压缩成关键时刻的关键词；这是速度滑冰报道，不能当作篮球现场逐句语料。央视[《今天的精彩，明天的传奇》文字实录](https://sports.cctv.com/lm/485/11/80064.html)涉及于嘉、徐济成在开赛前查核 NBA 官方阵容、面对临场变化修正认识。产品据此坚持姓名与结果有证据再说，并采用简短普通话动作句；不复制其台词。

万里出版社提供的[《说篮高手》试读](https://www.wanlibk.com/readers/preread/9789621473912.pdf)推荐序谈及张丕德的充分准备、客观评述与 NBA 文化理解。它不是香港粤语现场逐字稿，也不足以验证粤语语调。产品采用原创香港粤语口语、基础动作词与克制的情绪变化；是否自然仍须能听懂粤语的人试听成片。

工程落点：`beats` 仍为最多三个视觉分析节点，官方指标与来源绑定保留；可选 `commentaryCues` 为独立口播，最多六十句，每句引用已接受观察。出手、传球、接球仅在锚点与全部已引用帧可用后开口；结果和时间窗结论等待观察结束。口播起点最晚为证据可用时刻加三秒，单句最长八秒，不把一个旧事件拉长成整片串场。两项上限是产品编辑门槛，并非研究测得的解说员行为规律。

口播不读 xFG、GRAV、LVG、胜率、百分比或指标占位符。球衣号须有观察支持；已确认结果才可庆祝。无当前动作证据的区间允许留白。三种语言均可按已复核动作类型生成原创短句模板；普通话可保留已复核的短观察，较长描述退为基本动作词。结果模板须有明确且无矛盾的命中或未进表述。模型或人工可进一步写自然草稿，仍须逐句审核。文字预算只是编辑估算，最终必须实测音频窗口、完整句尾与姓名发音。此模块没有把公开文字研究标成音频自然度验收。
