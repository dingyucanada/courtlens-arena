# CourtLens 版本、入口与比赛交付

当前唯一参赛产品是 **CourtLens Broadcast**。`/broadcast/` 是产品路径，但不同部署环境承载的能力不同；不能用 Pages 展示页代替比赛 CloudFront 作品。

| 入口 | 定位 | 实际可做 | 数据与媒体 |
| --- | --- | --- | --- |
| GitHub Pages `/broadcast/` | 公开互动演练 | 播放自制合成样片、随视频时间显示对应解说与证据、跳转三个回合，展示真实片实测记录与限制 | 固定合成素材；无 API、账户、上传或真实片成片 |
| 本地 `http://127.0.0.1:8769/broadcast/` | 当前完整制作台 | 上传、真实帧提取、模型/CV 候选、人工复核、指标绑定、故事编辑、配音、MP4/VTT 发布 | 项目与媒体存在本机 `workspace/`，不进 Git |
| 比赛 CloudFront `/broadcast/` | 最终交付目标 | 与本地相同的产品工作流，接入赛方资源和指定 AWS Agent 服务后验收 | **尚未部署，AWS 账户与 Portal 数据未下发** |
| GitHub Pages `/demo.html?play=p01&view=fan` | 历史合成回合演练 | 拖动 36 秒视频、切换球迷/分析师视角、查看注释和可复算证据 | 自制合成 3 回合、12 段字幕；不代表 NBA 真片 |

`/arena.html` 和 `/studio.html` 先前公开的原型页面已从 Pages 交付包撤下。实现仍保留于 `pro/`、`studio/`，供已经核验的指标和媒体模块复用；它们没有独立品牌、参赛入口或并行产品路线。旧链接若仍能打开，应视为浏览器或 CDN 缓存，刷新后以本表为准。

## 截图里的真实 48 秒视频

截图来自**本地 Broadcast 项目** `6c3687c163214e9899dba0687a0bea9a`，源片为 NBA 官方频道 2025-01-01 独行侠对火箭集锦的前 48 秒。这是开发测试片，含剪辑和重放，**不是赛方即将提供的两段训练回合**。本地 release `9752829423b04928aaf8c4da0e55b24f` 已生成 48 秒 MP4、普通话配音与字幕。完整运行记录见 [真实 NBA 验证](Broadcast-真实NBA验证.md)，数据状态见 [深度数据接入状态](Broadcast-深度数据接入状态.md)。

启动 `python3 tools/launch.py --port 8769` 后，在本机打开 `http://127.0.0.1:8769/broadcast/?project=6c3687c163214e9899dba0687a0bea9a`。项目媒体在 Git 忽略的 `workspace/`；没有视频再分发授权，不把测试原片和衍生成片放上公共 Pages。赛方训练素材是**两段合计约 48 秒**，尚未下发。

## 同一品牌与交付包

统一使用 `CourtLens` 的 **C↗** 标记、夜场黑 `#070B14`、球场蓝 `#1769FF` 和关键红 `#E7354B`。红色表示叙事焦点或需要注意的状态，模型错误仍要有文字状态，不能仅靠颜色区分。旧 Arena 的金色/橙色和 Studio 的另一枚标记不再出现在公开导航。

公开包与比赛应用包分开构建：

```sh
python3 tools/build_site.py --mode pages --output site-dist
python3 tools/build_site.py --mode cloud --output dist
```

`pages` 只含展示页、合成演练及其媒体；其中 36 秒红蓝版配音成片位于 `media/broadcast-rehearsal.mp4`。`cloud` 含真实 Broadcast 编辑器，不会把静态介绍页覆盖到产品入口。旧截图、旧橙色成片是不可变的历史测试证据，不能误当新版外观。部署前必须用比赛账户、指定区域和 Agent 服务完成 [AWS 实际验收](Broadcast-AWS部署.md)。`dist` 应为干净目录，避免把旧 Pages 媒体混入比赛包。

## 功能与接口归属

用户主路径是 **选片 → 看懂 → 讲清 → 出片**。浏览器只负责操作与预览；`core/broadcast/` 是项目状态、修订、审核和发布的唯一业务入口；`contracts/broadcast-v1.json` 定义交换结构；`cloud/` 将同一业务合同接到托管任务与私有对象存储；`infra/` 是 CDK。检测输出和大模型文字都是候选，只有与实际源帧、时间锚和来源匹配并复核后才能进成片。官方 xFG、Gravity、LVG 缺失时不填合成值。

| 阶段 | 观众/制作人的操作 | 主要接口（`/api/broadcast/v1`） | 判断完成的依据 |
| --- | --- | --- | --- |
| 选片 | 建项目、上传、确认来源、导入同场名单/逐回合背景与官方指标 | `POST /projects`、本地 `/projects/{id}/media` 或云端 `/uploads`→`/media/commit`、`/projects/{id}/edit`、`/projects/{id}/metrics` | 源片 SHA-256、PTS 与修订号持久化；数据来源/粒度明确 |
| 看懂 | 选择分析时窗、运行模型或 CV、回看真实帧、接受/修正观察 | `POST /projects/{id}/analyze`、`/cv`、`/frames`、`/edit`；`GET /jobs/{id}` | 候选来源可追溯；确认身份有实际帧与同场名单依据；失败可重试 |
| 讲清 | 将事件与指标绑定，编辑最多三段解释和短时箭头 | `POST /projects/{id}/edit`、`/story`；`GET /tactics` 只供概念检索 | 每句话有可用时刻及来源引用；数据事件键与作用域匹配 |
| 出片 | 审核当前版本、选择可用音轨、导出、观看和下载 | `POST /projects/{id}/review`、`/render`；`GET /jobs/{id}`、`/releases/{id}` | 当前修订的审核有效；完整 MP4/VTT/manifest 已生成；历史成片不可变 |

这张表是**已实现的本地合同**，不是 AWS 实机验收。浏览器中“AI 分析”只有能力查询返回实际可用的提供者才出现；模型关闭时可走人工辅助路径，并在成片记录中保留制作方式。比赛现场输入以官方 Portal 字典为准，错误键、缺失值和未经确认的球员身份不能以界面文案绕过验证。
