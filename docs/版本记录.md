# 版本记录

## v3.0 · 2026-09-22

公开入口升级为实际可保存的浏览器工作室：七个工作页面、IndexedDB 视频与项目、CSV / JSON 导入、回合编辑与复核、筛选分析、投篮位置图、片单编排、真实 WebM 录制、可打印报告、版本历史与备份。保留旧证据演示和 Python 本机高级工作台。修复独立审查发现的导入 ID 注入、未保存内容丢失、异步绑定错项目及时间精度问题，并新增回归检查。详见 Studio验收报告。


## v2 · 2026-09-22

从可交互演练扩展为本机单用户产品：持久项目库、视频保存、CSV适配、回合编辑、版本历史/409冲突保护、人工画面标注、质量门槛、固定版本后台导出、取消和重启恢复，以及可选macOS中文配音。

产品仍以来源证据为中心；不把人工工作包装为自动识别，不把合成指标当成NBA测量。后续优先工作是按正式数据字典做真实适配、逐镜头校准和Agent云调用验收，再根据真实用户使用决定多人协作与部署。

原型迭代和产品最终验收见“最终验收报告”。
