# CourtLens Broadcast 产品边界

本项目当前目标是 Broadcast：源片单回合语义 proposal → 定向取证 → 严格数据绑定 → 最多三条故事 → 署名复核（明确人工或AI） → MP4 与 CloudFront 观赛。故事里的模型观察始终先作为待审提案；只有真实源片帧、确认的数据来源和署名复核能支撑最终表达；AI复核不得宣称人类确认。不得把合成样例或离线 CDK synth 写成比赛正式验收。

云匿名观众只播放已发布的解说版；源片和取证帧维持私有。原片对比在本地可用；云发布清单明确标明私有源片不可播放，直至实现具备授权和准确偏移的 release-scoped 片段。
